# Obsidian Auto Breadcrumbs

An automated, Notion-like breadcrumb navigation bar and bookmarks quick switcher for Obsidian desktop and mobile — completely zero-config and without manual frontmatter properties.

## Features

- **Zero Properties Needed:** Automatically resolves folder paths and links them to corresponding note files.
- **Smart Two-Level Search:** Matches folder names to notes inside the folder or directly one level above, stripping numerical or emoji prefixes cleanly.
- **Native Bookmarks Quick Switcher:** Displays a clean, hoverable/clickable dropdown with all your native Obsidian bookmarks.
- **Desktop & Mobile Ready:** Adapts cleanly to the desktop view header or the note header on mobile screens.
- **Declarative Settings:** Fully compliant with Obsidian 1.13+ settings search.

## Installation

### From Community Plugins
Search for **Auto Breadcrumbs** in Obsidian Settings > Community Plugins and click install.

### Manual Installation
1. Download `main.js`, `manifest.json`, and `styles.css` from the latest release.
2. Create a folder named `auto-breadcrumbs` under `<vault>/.obsidian/plugins/`.
3. Copy the three files into that folder.
4. Reload Obsidian and activate the plugin in the Community Plugins menu.
